## Motivation
Precision Time Protocol (PTP) is a network protocol that synchronizes clocks across a network to sub-microsecond or nanosecond accuracy. PTP provides high precision time for safety critical control applications. Security is of utmost priority in such applications. PTP relies on timestamp acquisition, network drivers, clock adjustment and scheduling and these components can be tampered in a compromised OS which compromizes PTP security. The motivation for this project comes from this gap in security in PTP's current implementation. We aim to study, explore and implement techniques like using security enclaves or TEE (Trusted execution Environments) to make PTP more secure.
